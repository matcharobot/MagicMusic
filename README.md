### Installation
我们将MM分为两部分进行运行
M4Singer requires Python 3.8, torch 2.2.2. Please refer to [M4Singer](https://github.com/M4Singer/M4Singer) to install the M4Singer.
```shell
pip install -v -r requirements.txt
```
